# 调酒 Demo 产品决策

## AI 可视化形象

- AI 形象采用 **“聆听之杯”**。
- 它不是人形酒保，也不是卡通吉祥物，而是一只像能听懂用户口味、材料和心情的高级酒杯。
- 不要给酒杯加脸、眼睛、嘴巴，避免变幼稚。
- 用杯型、酒液颜色、冰块、气泡、杯沿微光和克制动效来表达状态。
- 当用户输入口味或材料时，酒杯可以像是在“聆听”和“思考”。
- 当推荐生成时，杯中酒液可以变成对应鸡尾酒的色调，像是把结果显影出来。
- 产品定位：一个安静、有品味的线上酒保，帮助用户把当下心情、口味偏好和现有材料，转化成一杯真实可调的经典鸡尾酒。

## UI 视觉方向

- 整体视觉采用 **亮色、高级、优雅、简约的轻奢生活方式 App** 方向。
- 主体色调使用象牙白、暖米白、浅香槟金、浅灰米色。
- 避免大面积高饱和颜色，让不同颜色的鸡尾酒都能适配。
- 界面气质应像高端酒单、收藏卡片和现代移动应用的结合。
- 整体要干净、有留白、层级清楚，带一点精品酒吧和生活方式杂志感。
- 不要手绘感太强，不要暗黑夜店感，不要花哨装饰。

## UI 细节约束

- 使用大面积浅色背景、柔和阴影和圆角卡片。
- 使用细线边框、浅金色分割线、轻量徽章和编号。
- 标签、筛选项使用浅色 pill 样式。
- 标题可使用偏宋体或 serif 风格，正文使用清晰现代无衬线。
- 视觉层级要克制，优先保证内容可读和组件复用。

## 酒图风格

- 酒图必须适合用 SVG 组件化生成。
- 避免水彩、手绘、真实插画或重摄影质感。
- 使用干净的矢量风格：统一线条粗细、简化几何形状、扁平色块和少量透明渐变。
- 玻璃杯、冰块、柠檬、薄荷、吸管、盐边、糖边等都应作为可复用 SVG 组件。
- 每杯酒的颜色可以作为局部主题色，但 UI 主体保持中性百搭。

## 最终视觉目标

做成一个亮色、高级、百搭、可组件化实现的鸡尾酒推荐与分享 App 界面系统。

## 产品节奏决策

- 当前阶段优先做“推荐结果强化”，不是完整分享闭环。
- MVP 的核心闭环是：输入需求、推荐经典酒、展示 SVG 酒图、给出材料与步骤。
- 结果页是当前最重要的页面，必须把推荐理由、酒图、已有材料、缺失材料、步骤和一句酒保建议做清楚。
- 用户上传照片、手动裁切、成果卡片、多文案风格都后置到分享阶段。
- 经典 twist 有价值，但第一阶段不做完整规则引擎，只在后续支持“不太烈、清爽、不要苦、果味”这类高频小改编。
- `lyric_mood` 歌词氛围文案优先级最低，因为版权约束复杂，且不是推荐闭环的必要能力。
